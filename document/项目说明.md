# 知堂 · 项目说明

## 一、项目定位

**知堂（my-lesson）** 是一套完整的线上网课售卖与学习平台解决方案，覆盖：

- **学员侧**：微信小程序选课、看课、发弹幕、购买课程
- **运营侧**：Web 后台管理课程内容与营销活动
- **服务端**：Spring Cloud 微服务支撑高并发与可扩展架构

适用于在线教育平台原型验证、全栈项目展示与技术学习。

---

## 二、业务场景

### 典型学员路径

```
打开小程序 → 浏览首页推荐 / 整点秒杀 → 进入课程详情 → 播放试看/正式课时
    → 发送弹幕 → 加入购物车 → 下单支付 → 我的课程学习
```

### 典型运营路径

```
登录后台 → 上架课程（分类/章节/课时）→ 上传封面与视频到 MinIO
    → 配置首页轮播与秒杀活动 → 管理用户订单与评论举报
```

## 三、与代码模块的对应关系

| 业务概念 | 代码实体 | 所属服务 |
|----------|----------|----------|
| 课程 | `Course` | ml-course |
| 章节 | `Season` | ml-course |
| 课时 | `Episode` | ml-course |
| 分类 | `Category` | ml-course |
| 评论 / 举报 / 关注 | `Comment` / `Report` / `Follow` | ml-course |
| 弹幕 | `BarrageDoc` (ES) | ml-barrage / ml-course |
| 购物车 | `Cart` | ml-order |
| 订单 / 订单明细 | `Order` / `OrderDetail` | ml-order |
| 轮播图 / 公告 / 文章 | `Banner` / `Notice` / `Article` | ml-sale |
| 秒杀活动 / 活动明细 | `Seckill` / `SeckillDetail` | ml-sale |
| 优惠券 | `Coupons` | ml-sale |
| 用户 / 角色 / 菜单 | `User` / `Role` / `Menu` | ml-user |

> 说明：实体类名 `Season` / `Episode` 沿用英文命名，在业务上分别对应**章节**与**课时**，即「课程 → 章节 → 课时」三级内容模型。

## 四、中间件职责

| 中间件 | 用途 |
|--------|------|
| Nacos | 服务注册发现、集中配置（数据库、Redis、Token 白名单等） |
| MySQL | 业务持久化，四库分离（`ml_ums` / `ml_cms` / `ml_oms` / `ml_sms`） |
| Redis | Token 会话、秒杀库存与限流、热点课程信息 |
| Elasticsearch | 弹幕存储与检索、课程搜索 |
| MinIO | 课程封面、课时视频、头像、轮播图等静态资源 |
| RocketMQ | 秒杀异步建单、订单超时取消延迟消息 |
| XXL-JOB | 秒杀活动库存预热与整点开关调度 |
| WebSocket | 弹幕实时广播 |
| 支付宝当面付 | 扫码支付、异步回调验签、主动查单兜底 |

## 五、接口访问规范

所有 HTTP 接口经网关 `ml-gateway` 转发，路径格式：

```
http://{gateway}/{service-name}/api/v1/{module}/{action}
```

示例：

```
GET  /course-server/api/v1/course/page                     # 课程分页
GET  /course-server/api/v1/episode/searchBarrage/course/1  # 课程弹幕
POST /user-server/api/v1/user/loginByAccount               # 登录
POST /sale-server/api/v1/seckill/kill                      # 秒杀抢课
WS   ws://{host}:24106/api/v1/barrage/{userId}             # 弹幕
```

请求头需携带 `token`（登录后获取，白名单接口除外）。
