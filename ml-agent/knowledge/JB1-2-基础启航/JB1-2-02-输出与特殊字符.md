## 2.1 换行与同行输出

**本课时对应知识点**：换行输出语句、不换行输出语句、空内容输出效果。

**两个基本输出方法**：

```java
System.out.println("内容");   // print line：输出后换行
System.out.print("内容");     // print：输出后不换行
```

**对比示例**：

```java
System.out.print("A");
System.out.print("B");
System.out.print("C");
// 输出：ABC（在同一行）

System.out.println("A");
System.out.println("B");
System.out.println("C");
// 输出：
// A
// B
// C
```

**空内容输出的差异（考点）**：

```java
System.out.println();      // ✅ 合法：输出一个空行（相当于只按了个回车）
System.out.print();        // ❌ 编译错误：print() 没有无参重载
```

原因：`println()` 有一个无参重载版本，语义是「只换行」；而 `print()` 必须传参数，因为「打印空内容且不换行」等于什么都没做，没有存在意义。

**`System.out` 到底是什么**。`System` 是 `java.lang` 包下的系统类；`out` 是它的一个 **static 字段**，类型是 `PrintStream`（打印流，见 JB1-4 流类之打印流）；`println` 是 `PrintStream` 类的方法。所以 `System.out.println()` 的完整含义是「调用系统类的标准输出流对象的打印换行方法」。

**三个标准流**：

```java
System.out    // 标准输出，控制台白色文字
System.err    // 标准错误输出，IDEA 中显示为红色
System.in     // 标准输入，用于读取键盘输入
```

```java
System.out.println("普通信息");
System.err.println("错误信息");   // IDEA 中显示为红色，用于醒目提示
```

> 注意：`System.out` 和 `System.err` 是两个独立的流，输出顺序在控制台中**可能交错**（因为缓冲机制不同），调试时不要依赖它们的相对顺序。

**`println()` 的重载**。它可以接收任意类型，因为 `PrintStream` 为每种类型都提供了重载版本：

```java
System.out.println(100);          // int
System.out.println(3.14);         // double
System.out.println('A');          // char
System.out.println(true);         // boolean
System.out.println("字符串");      // String
System.out.println(new User());   // Object —— 实际打印的是 toString() 的结果
```

传对象时会自动调用该对象的 `toString()` 方法。如果类没重写 `toString()`，打印出来是 `com.mdkj.User@1b6d3586` 这种「类名@哈希码」的形式（见 JB1-3 龙目岛工具类的 `@ToString`）。

**读取键盘输入**（配套知识）：

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);
System.out.print("请输入姓名：");     // 用 print 不换行，光标停在提示后面，体验更好
String name = sc.nextLine();
System.out.println("你好，" + name);
sc.close();
```

`Scanner` 常用方法：`nextInt()` 读整数、`nextDouble()` 读小数、`next()` 读单词（遇空格结束）、`nextLine()` 读整行。

> **经典坑**：`nextInt()` 之后紧跟 `nextLine()` 会直接返回空字符串 —— 因为 `nextInt()` 只读走了数字，没读走后面的回车符，`nextLine()` 一上来就遇到了这个残留回车。解决办法是在中间多加一次 `sc.nextLine()` 把回车消耗掉。

## 2.2 格式化输出语句

**本课时对应知识点**：格式化输出语句的使用方式、常用占位符。

**为什么需要格式化输出**。用字符串拼接输出多个变量既啰嗦又难控制格式：

```java
// 拼接方式：可读性差，无法控制小数位数和对齐
System.out.println("姓名：" + name + "，年龄：" + age + "，成绩：" + score);

// 格式化方式：模板清晰，格式可控
System.out.printf("姓名：%s，年龄：%d，成绩：%.2f%n", name, age, score);
```

**两个格式化方法**：

```java
System.out.printf("格式模板", 参数1, 参数2, ...);   // 直接输出，不换行
String s = String.format("格式模板", 参数1, ...);   // 返回字符串，不输出
```

`printf` 的 `f` 是 format 的意思。它**不会自动换行**，需要手动在末尾加 `%n` 或 `\n`。

**常用占位符**：

| 占位符 | 类型 | 示例 | 输出 |
|---|---|---|---|
| `%d` | 整数（decimal） | `printf("%d", 100)` | `100` |
| `%f` | 浮点数，默认 6 位小数 | `printf("%f", 3.14)` | `3.140000` |
| `%.2f` | 浮点数保留 2 位（**四舍五入**） | `printf("%.2f", 3.14159)` | `3.14` |
| `%s` | 字符串 | `printf("%s", "abc")` | `abc` |
| `%c` | 字符 | `printf("%c", 'A')` | `A` |
| `%b` | 布尔 | `printf("%b", true)` | `true` |
| `%e` | 科学计数法 | `printf("%e", 12345.6)` | `1.234560e+04` |
| `%x` / `%X` | 十六进制 | `printf("%x", 255)` | `ff` / `FF` |
| `%o` | 八进制 | `printf("%o", 8)` | `10` |
| `%%` | 输出百分号本身 | `printf("100%%")` | `100%` |
| `%n` | 换行（**跨平台**） | —— | 换行 |

**宽度与对齐控制**（做表格输出时很实用）：

```java
System.out.printf("%5d%n", 42);        // "   42"   宽度5，右对齐（默认）
System.out.printf("%-5d|%n", 42);      // "42   |"  宽度5，左对齐（负号）
System.out.printf("%05d%n", 42);       // "00042"   宽度5，前面补0
System.out.printf("%10.2f%n", 3.14159);// "      3.14" 宽度10，2位小数
System.out.printf("%,d%n", 1234567);   // "1,234,567" 千分位分隔
System.out.printf("%+d%n", 42);        // "+42"     强制显示正号
```

**表格化输出示例**：

```java
System.out.printf("%-10s%-6s%-8s%n", "姓名", "年龄", "成绩");
System.out.printf("%-10s%-6d%-8.1f%n", "张三", 20, 95.5);
System.out.printf("%-10s%-6d%-8.1f%n", "李四", 22, 88.0);
```

**`%n` 与 `\n` 的区别（重要）**：

| | `\n` | `%n` |
|---|---|---|
| 本质 | 转义字符，固定是 LF（`\u000A`） | 格式化占位符，输出**平台相关**的换行符 |
| Windows | 输出 LF | 输出 CRLF（`\r\n`） |
| Linux/macOS | 输出 LF | 输出 LF |
| 适用范围 | 任何字符串 | **只能用在格式化方法里** |

**推荐在 `printf` 中用 `%n`**，跨平台更安全。在普通字符串里只能用 `\n`。

**参数数量必须匹配**。占位符个数与参数个数不一致会抛运行时异常：

```java
System.out.printf("%s-%s%n", "只有一个参数");
// MissingFormatArgumentException: Format specifier '%s'
```

类型不匹配也会报错：`printf("%d", "abc")` 抛 `IllegalFormatConversionException`。

## 2.3 输出基础表达式

**本课时对应知识点**：输出语句中允许直接使用表达式、`+` 的字符串拼接效果。

**输出语句可以直接放表达式**，会先求值再输出：

```java
System.out.println(1 + 2);              // 3     先算术运算
System.out.println(10 > 5);             // true  先关系运算
System.out.println(3 * 4 + 2);          // 14
System.out.println(getUserName());      // 先调用方法，输出返回值
```

**`+` 的双重身份（本课时最重要的考点）**。`+` 在 Java 中有两种含义，取决于**操作数的类型**：

- 两边**都是数字** → **算术加法**
- 有**任意一边是字符串** → **字符串拼接**，另一边自动转成字符串

```java
System.out.println(1 + 2);              // 3        数字 + 数字 = 加法
System.out.println("1" + 2);            // "12"     字符串 + 数字 = 拼接
System.out.println(1 + 2 + "岁");        // "3岁"    从左往右：(1+2)=3，再拼"岁"
System.out.println("岁" + 1 + 2);        // "岁12"   从左往右：("岁"+1)="岁1"，再拼2
```

**关键规则：`+` 从左向右结合**。这解释了上面两个看似矛盾的结果 —— 计算顺序不同，结果完全不同。这是初学者最容易出错的地方，也是面试常考点。

**用括号强制改变顺序**：

```java
System.out.println("结果：" + 1 + 2);      // "结果：12"   ❌ 不是想要的
System.out.println("结果：" + (1 + 2));    // "结果：3"    ✅ 加括号
```

**更多易错示例**：

```java
System.out.println('a' + 1);            // 98    char 参与算术运算，'a' 的码值是 97
System.out.println("" + 'a' + 1);       // "a1"  先与空串拼接，'a' 变成字符串
System.out.println('a' + 1 + "");       // "98"  先算 'a'+1=98，再拼空串
System.out.println((char)('a' + 1));    // 'b'   强转回 char
System.out.println(1 + 2 + "3" + 4 + 5);// "3345" (1+2)=3 → "33" → "334" → "3345"
```

**空值的拼接**：

```java
String s = null;
System.out.println("值：" + s);          // "值：null"  不会报空指针，会输出字面量 "null"
System.out.println(s.length());         // ❌ NullPointerException
```

字符串拼接对 `null` 是安全的（内部会转成 `"null"` 字符串），但**调用 null 的方法一定报空指针**。

**性能提示**。循环里用 `+` 拼接字符串性能很差 —— 每次拼接都会创建新的 String 对象和 StringBuilder：

```java
// ❌ 循环里禁止这样写
String result = "";
for (int i = 0; i < 10000; i++) {
    result += i;        // 每次都新建对象，10000 次产生大量垃圾
}

// ✅ 正确做法：用 StringBuilder（见 JB1-4 字符拼接工具）
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);
}
String result = sb.toString();
```

阿里巴巴 Java 开发手册明确规定：循环体内不要使用 `+` 进行字符串拼接。

## 2.4 输出特殊的字符

**本课时对应知识点**：跳格、回行、换行、转义字符。

**为什么需要转义字符**。有些字符无法直接写在字符串里：双引号会提前结束字符串，反斜杠有特殊含义，Tab 和换行无法直接输入。**转义字符用反斜杠 `\` 开头**，把特殊字符「转义」成普通字符，或把普通字母转义成控制字符。

**完整转义字符表**：

| 转义符 | 名称 | 效果 |
|---|---|---|
| `\n` | 换行（LF, Line Feed） | 光标移到下一行 |
| `\r` | 回车（CR, Carriage Return） | 光标移到**本行开头** |
| `\t` | 制表符 / 跳格（Tab） | 跳到下一个制表位（通常 4 或 8 字符） |
| `\b` | 退格（Backspace） | 光标左移一位 |
| `\f` | 换页（Form Feed） | 打印机换页，现代很少用 |
| `\'` | 单引号 | 输出 `'` |
| `\"` | 双引号 | 输出 `"` |
| `\\` | 反斜杠 | 输出 `\` |
| `\uXXXX` | Unicode 字符 | 如 `\u0041` 是 `A`，`\u4e2d` 是 `中` |
| `\0` | 空字符 | ASCII 码 0 |

**示例**：

```java
System.out.println("第一行\n第二行");
// 第一行
// 第二行

System.out.println("姓名\t年龄\t成绩");     // 用 \t 做列对齐
System.out.println("张三\t20\t95");

System.out.println("他说：\"你好\"");        // 他说："你好"
System.out.println("路径：C:\\Users\\Java"); // 路径：C:\Users\Java
System.out.println("单引号：\'");            // 单引号：'
System.out.println("\u0041\u0042\u0043");   // ABC
```

**`\n` 与 `\r` 的区别（历史遗留，面试常问）**：

这两个概念来自老式打字机：`\r`（回车）让打印头回到行首，`\n`（换行）让纸卷向上走一行。两个动作合起来才是「另起一行」。不同系统继承了不同的约定：

| 系统 | 换行符 | 写法 |
|---|---|---|
| **Windows** | CRLF | `\r\n` |
| **Linux / macOS** | LF | `\n` |
| 早期 Mac（OS 9 及以前） | CR | `\r` |

**这个差异的实际影响**：

- 在 Windows 上用记事本打开 Linux 生成的文本文件，所有内容挤成一行（老版本记事本）
- Git 提交时可能出现「整个文件都被修改」的假象（换行符被转换）—— 可以用 `git config --global core.autocrlf true` 处理
- 用 `\r` 可以实现**原地刷新**的进度条效果：

```java
for (int i = 0; i <= 100; i += 10) {
    System.out.print("\r进度：" + i + "%");     // \r 回到行首覆盖，不换行
    Thread.sleep(200);
}
System.out.println();
```

**推荐做法：不要硬编码换行符**：

```java
String lineSeparator = System.lineSeparator();   // 自动获取当前系统的换行符
// 或在格式化输出中用 %n
System.out.printf("第一行%n第二行%n");
```

**文本块（Text Block，JDK 15+ 正式特性）**。多行字符串不用再拼 `\n`：

```java
String json = """
        {
            "name": "张三",
            "age": 20
        }
        """;

String sql = """
        SELECT id, title, price
        FROM course
        WHERE deleted = 0
        ORDER BY idx
        """;
```

用三个双引号包裹，内部的换行和缩进被原样保留（以结束标记的缩进为基准去除公共前导空白）。写 JSON、SQL、HTML 时非常方便，是 JDK 17 / 21 / 25 项目中值得优先使用的写法。

**Unicode 转义的特殊性**。`\uXXXX` 在**编译前的词法分析阶段**就会被替换，这导致一个著名的陷阱：

```java
// \u000A 是换行符，会在编译期变成真正的换行，导致这行注释「断开」
// 下面这行代码看起来是注释，其实会编译报错：
// int a = 1; \u000A int b = 2;
```

正因如此，注释里也不要随意出现 `\u` 开头的序列。
