## 8.1 选择之范围匹配

**本课时对应知识点**：`if(条件){ } else if(条件){ } else{ }` 基础格式。

**为什么叫「范围匹配」**：`if` 的条件是**布尔表达式**，可以表达任意复杂的判断 —— 大于小于、区间、组合条件。这是它相对 `switch` 的核心优势。

**三种形式**：

**① 单分支 if**：

```java
if (条件) {
    // 条件为 true 时执行
}
```

```java
int score = 85;
if (score >= 60) {
    System.out.println("及格了");
}
```

**② 双分支 if-else**：

```java
if (条件) {
    // true 时执行
} else {
    // false 时执行
}
```

```java
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

**③ 多分支 if-else if-else**：

```java
if (条件1) {
    // 条件1 成立
} else if (条件2) {
    // 条件1 不成立且条件2 成立
} else if (条件3) {
    // 前面都不成立且条件3 成立
} else {
    // 所有条件都不成立
}
```

```java
int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");      // ← 匹配这里
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

**关键规则：从上往下依次判断，命中第一个成立的分支后立即结束，后面的一律不再判断**。

正因为如此，**条件的书写顺序至关重要**：

```java
// ❌ 错误顺序：score=95 会命中第一个 >= 60，永远到不了「优秀」
if (score >= 60) { System.out.println("及格"); }
else if (score >= 80) { System.out.println("良好"); }
else if (score >= 90) { System.out.println("优秀"); }

// ✅ 正确顺序：范围从严到宽
if (score >= 90) { ... }
else if (score >= 80) { ... }
else if (score >= 60) { ... }
```

**由于「命中即停」的特性，后面的条件天然带有前面条件的否定**。`else if (score >= 80)` 实际含义是 `score < 90 && score >= 80`，不需要重复写上界。

**书写规范与常见坑**：

**① 大括号不要省略**。语法上单条语句可以省略 `{}`，但**强烈建议永远写上**：

```java
if (score >= 60)
    System.out.println("及格");
    System.out.println("恭喜");     // ❗ 这行不属于 if！无论如何都会执行
```

缩进有欺骗性，实际只有第一行属于 if。历史上著名的 Apple「goto fail」安全漏洞就源于这类问题。阿里巴巴开发手册强制要求：**在 if/else/for/while/do 语句中必须使用大括号**。

**② 分号不要多写**：

```java
if (score >= 60);           // ❗ 分号使 if 体变成空语句
{
    System.out.println("及格");   // 这段无条件执行
}
```

**③ 条件必须是 boolean**：

```java
int a = 1;
if (a) { ... }              // ❌ 编译错误（C 语言可以，Java 不行）
if (a == 1) { ... }         // ✅
```

**④ 判断 boolean 变量不要写 `== true`**：

```java
if (flag == true) { ... }   // ❌ 冗余，且容易误写成 =
if (flag) { ... }           // ✅
if (!flag) { ... }          // ✅
```

**嵌套 if**：

```java
if (user != null) {
    if (user.isActive()) {
        if (user.hasPermission()) {
            // 业务逻辑
        }
    }
}
```

**嵌套超过两层就该重构**。推荐用**卫语句**（见第 4 单元 4.4 课时）：

```java
if (user == null) return;
if (!user.isActive()) return;
if (!user.hasPermission()) return;
// 业务逻辑，零缩进
```

**if 与三目运算符的选择**：简单的二选一**取值**用三目（`int max = a > b ? a : b;`）；需要执行多条语句或有副作用时用 if-else。

**变量作用域**：在 if 内部声明的变量，出了大括号就失效：

```java
if (true) {
    int x = 10;
}
System.out.println(x);      // ❌ 编译错误：找不到符号
```

## 8.2 选择之定值匹配

**本课时对应知识点**：`switch(表达式){ case 匹配值: break; }` 基础格式。

**为什么叫「定值匹配」**：`switch` 只能判断**表达式的值是否等于某个确定的常量**，不能表达范围。适合状态码、类型、枚举这类离散取值。

**基础格式**：

```java
switch (表达式) {
    case 值1:
        // 语句
        break;
    case 值2:
        // 语句
        break;
    default:
        // 都不匹配时执行
        break;
}
```

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("星期一");
        break;
    case 2:
        System.out.println("星期二");
        break;
    case 3:
        System.out.println("星期三");    // ← 匹配这里
        break;
    default:
        System.out.println("输入有误");
        break;
}
```

**switch 支持的数据类型**：

| 类型 | 支持情况 |
|---|---|
| `byte`、`short`、`int`、`char` | ✅ 从最初就支持 |
| 对应的包装类 `Byte`/`Short`/`Integer`/`Character` | ✅ JDK 5+（自动拆箱） |
| `enum` 枚举 | ✅ JDK 5+ |
| `String` | ✅ **JDK 7+** |
| `long`、`float`、`double`、`boolean` | ❌ **不支持** |

**为什么不支持 long**：switch 底层用 `tableswitch` 或 `lookupswitch` 字节码指令实现，这两条指令的操作数是 int。long 超出 int 范围，无法用这套机制。float/double 因为精度问题不适合做相等判断，boolean 只有两个值用 if 更合适。

**`break` 的作用与「击穿」现象（本课时最重要的考点）**：

**没有 `break` 会继续执行后面所有 case 的代码，直到遇到 break 或 switch 结束** —— 这叫 **case 穿透（fall-through）**：

```java
int day = 1;
switch (day) {
    case 1:
        System.out.println("一");     // 匹配后开始执行
    case 2:
        System.out.println("二");     // 没有 break，继续执行！
    case 3:
        System.out.println("三");     // 继续！
}
// 输出：一 二 三
```

**忘写 break 是初学者最高频的 switch 错误**。

**但穿透有时是刻意利用的特性**（多个值执行同一逻辑）：

```java
switch (month) {
    case 1: case 3: case 5: case 7:
    case 8: case 10: case 12:
        days = 31;
        break;
    case 4: case 6: case 9: case 11:
        days = 30;
        break;
    case 2:
        days = isLeapYear ? 29 : 28;
        break;
    default:
        throw new IllegalArgumentException("月份非法：" + month);
}
```

**`default` 分支**：

- **位置可以在任意处**（习惯放最后），不匹配任何 case 时执行
- **可以省略**，但**强烈建议总是写上** —— 用来兜底非法输入，暴露问题而不是静默忽略
- 阿里巴巴开发手册规定：`switch` 必须包含 `default` 语句并且放在最后，即使空代码也要写

**String 类型的 switch（JDK 7+）**：

```java
String cmd = "start";
switch (cmd) {
    case "start":
        System.out.println("启动");
        break;
    case "stop":
        System.out.println("停止");
        break;
    default:
        System.out.println("未知命令");
}
```

底层实现是先比较 `hashCode()` 再用 `equals()` 确认（防哈希碰撞），本质仍是 int 的 switch。**注意 `cmd` 为 null 时会抛 NullPointerException**，使用前需判空。

**枚举类型的 switch（推荐用法）**：

```java
enum Status { PENDING, PAID, CANCELLED }

switch (status) {
    case PENDING:      // 注意：不写 Status.PENDING，直接写常量名
        System.out.println("待付款");
        break;
    case PAID:
        System.out.println("已付款");
        break;
    case CANCELLED:
        System.out.println("已取消");
        break;
}
```

枚举 + switch 是表达状态机的最佳组合：编译器能检查是否遗漏了某个枚举值，类型安全，可读性也最好。

**switch 表达式（JDK 14+ 正式特性，强烈推荐）**：

新语法用箭头 `->`，**不会穿透，不需要 break**，而且可以**直接返回值**：

```java
// 箭头形式，无需 break
switch (day) {
    case 1 -> System.out.println("星期一");
    case 2 -> System.out.println("星期二");
    default -> System.out.println("其他");
}

// 作为表达式直接赋值
String name = switch (day) {
    case 1 -> "星期一";
    case 2 -> "星期二";
    case 6, 7 -> "周末";              // 多个值用逗号，不用写多行 case
    default -> "未知";
};

// 需要多条语句时用大括号 + yield 返回值
int result = switch (type) {
    case 1 -> 100;
    case 2 -> {
        int temp = compute();
        yield temp * 2;              // 用 yield 返回，不是 return
    }
    default -> 0;
};
```

**新语法的三大优势**：① 不会因忘记 break 而穿透；② 可以作为表达式赋值，代码更紧凑；③ 对枚举做穷尽性检查（覆盖了所有枚举值时可省略 default，漏了则编译报错）。

**JDK 17 / 21 / 25 的项目应优先使用箭头形式**。本平台（知堂课堂）用的是 Java 17，完全支持。

**if 与 switch 的选择**：

| 场景 | 推荐 |
|---|---|
| 范围判断（`>`、`<`、区间） | **if** |
| 复杂组合条件（`&&`、`\|\|`） | **if** |
| 判断 boolean | **if** |
| 等值判断且分支较多（≥3） | **switch** |
| 枚举状态处理 | **switch** |
| 需要多个值走同一逻辑 | **switch**（利用穿透或逗号语法） |

**性能说明**：分支较多时 switch 通常比 if-else 链快 —— `tableswitch` 指令可以按索引**跳表直达**，时间复杂度 O(1)；而 if-else 链需要逐个判断，最坏 O(n)。但在分支很少时差异可以忽略，**可读性才是首要考量**。
