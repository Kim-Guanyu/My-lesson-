## 9.1 仅知结束的条件

**本课时对应知识点**：`while(条件){ }`、`do{ }while(条件);` 基础格式。

**适用场景**：**不知道要循环多少次，只知道什么情况下该停下来**。例如「读文件直到读完」「用户输入直到输入正确」「猜数字直到猜对」。

### while 循环

```java
while (条件) {
    // 循环体
}
```

**执行流程**：先判断条件 → 为 true 则执行循环体 → 回到判断 → 直到条件为 false 结束。

```java
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;                    // ⚠️ 必须有能让条件变 false 的语句
}
// 输出 1 2 3 4 5
```

**while 的三要素（缺一不可）**：

```java
int i = 1;              // ① 初始化变量
while (i <= 5) {        // ② 判断条件
    System.out.println(i);
    i++;                // ③ 改变变量（否则死循环）
}
```

**忘记第 ③ 步是最经典的错误** —— 条件永远为 true，程序卡死。

**实际应用**：

```java
// 读取用户输入直到合法
Scanner sc = new Scanner(System.in);
int age = -1;
while (age < 0 || age > 150) {
    System.out.print("请输入年龄(0-150)：");
    age = sc.nextInt();
}

// 计算数字各位之和
int n = 12345, sum = 0;
while (n > 0) {
    sum += n % 10;      // 取末位
    n /= 10;            // 去掉末位
}
System.out.println(sum);    // 15
```

### do-while 循环

```java
do {
    // 循环体
} while (条件);          // ⚠️ 注意结尾有分号
```

**执行流程**：**先执行一次循环体** → 再判断条件 → 为 true 则继续 → 直到条件为 false。

```java
int i = 10;
do {
    System.out.println(i);   // 即使 i>5 不成立，也会先打印一次
    i++;
} while (i <= 5);
// 输出：10
```

**while 与 do-while 的唯一区别（本课时核心考点）**：

| | `while` | `do-while` |
|---|---|---|
| 判断时机 | **先判断，后执行** | **先执行，后判断** |
| 最少执行次数 | **0 次** | **1 次** |
| 语法结尾 | 无分号 | **有分号** |

```java
// 条件一开始就为 false 时的差异
int i = 10;

while (i <= 5) { System.out.println("while"); }        // 一次都不执行

do { System.out.println("do-while"); } while (i <= 5); // 执行了一次
```

**do-while 的典型场景：至少要执行一次的操作**：

```java
// 菜单系统：菜单必须先显示一次，用户才能选择
int choice;
do {
    System.out.println("1. 查询  2. 新增  0. 退出");
    choice = sc.nextInt();
    switch (choice) {
        case 1 -> query();
        case 2 -> add();
    }
} while (choice != 0);
```

实际开发中 `do-while` 用得比 `while` 少得多，但在「先做一次再检查」的场景下最贴切。

### 死循环

```java
while (true) {
    // 无限循环
    if (某条件) break;      // 靠 break 退出
}
```

**死循环并不总是错误**。服务器主循环、消息监听、游戏主循环都是刻意写成死循环的，靠 `break` 或 `return` 在特定条件下退出。

三种等价的死循环写法：`while (true)`、`for (;;)`、`do {} while (true)`。

**误写死循环的常见原因**：忘记改变循环变量；条件写反；在循环体内又把变量改回去了。**IDEA 中程序卡住时，点红色方块停止，检查循环条件**。

## 9.2 仅知循环的次数

**本课时对应知识点**：`for(初; 判; 变){ }` 基础格式。

**适用场景**：**明确知道要循环多少次**。例如「打印 1 到 100」「遍历数组每个元素」「重复执行 10 次」。

**基础格式**：

```java
for (初始化; 判断条件; 变化量) {
    // 循环体
}
```

```java
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
// 输出 1 2 3 4 5
```

**执行顺序（必须理解，考点）**：

```
① 初始化（只执行一次）
     ↓
② 判断条件 ────false───→ 结束循环
     ↓ true
③ 执行循环体
     ↓
④ 执行变化量
     ↓
   回到 ②
```

**注意 ③ 和 ④ 的顺序**：变化量（`i++`）是在**循环体执行完之后**才执行的，不是一进入循环就执行。

**for 与 while 的等价关系**：

```java
// for 写法
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

// 完全等价的 while 写法
int i = 0;              // ① 初始化
while (i < 5) {         // ② 判断
    System.out.println(i);  // ③ 循环体
    i++;                // ④ 变化量
}
```

**for 的优势在于把三要素集中写在一行**，不容易遗漏，作用域也更清晰（`i` 出了循环就销毁，而 while 写法中 `i` 会污染外部作用域）。

**for 的灵活写法**：

```java
// 倒序
for (int i = 5; i >= 1; i--) { ... }

// 步长为 2
for (int i = 0; i <= 10; i += 2) { ... }

// 多个变量（用逗号）
for (int i = 0, j = 10; i < j; i++, j--) { ... }

// 省略部分（分号不能省）
int i = 0;
for (; i < 5; i++) { ... }        // 省略初始化
for (int k = 0; ; k++) { if (k > 5) break; }   // 省略条件（等于 true）
for (;;) { ... }                  // 全省略 = 死循环
```

### 增强 for 循环（for-each，JDK 5+）

**专门用于遍历数组和集合**：

```java
for (元素类型 变量名 : 数组或集合) {
    // 使用 变量名
}
```

```java
int[] arr = {1, 2, 3, 4, 5};
for (int n : arr) {
    System.out.println(n);
}

List<String> list = List.of("a", "b", "c");
for (String s : list) {
    System.out.println(s);
}
```

**增强 for 的优势**：代码简洁、不会数组越界、不用管索引。

**增强 for 的三个限制**：

```java
// ① 拿不到索引
for (int n : arr) {
    // 无法知道当前是第几个元素
}

// ② 不能修改数组元素（n 只是副本）
for (int n : arr) {
    n = 100;            // ❗ 无效！arr 本身不变
}

// ③ 遍历集合时不能增删元素
for (String s : list) {
    list.remove(s);     // ❌ ConcurrentModificationException
}
```

**需要索引、需要修改元素、需要增删时，用普通 for 或迭代器**（见 JB1-4 迭代器遍历法）。

增强 for 遍历数组时编译后是普通 for；遍历集合时编译后是 `Iterator`（可以用 jclasslib 插件查看字节码验证）。

### 嵌套循环

```java
// 九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "×" + i + "=" + (i * j) + "\t");
    }
    System.out.println();       // 内层结束后换行
}

// 打印三角形
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```

**嵌套循环的执行规律**：**外层执行 1 次，内层执行完整一轮**。外层 m 次、内层 n 次，循环体总共执行 **m × n** 次。

**性能提醒**：嵌套循环的时间复杂度是 O(n²)，三层就是 O(n³)。数据量大时要警惕 —— 一万个元素的双层循环就是一亿次运算。

### break 与 continue

| 关键字 | 作用 |
|---|---|
| `break` | **终止整个循环**，跳出循环体 |
| `continue` | **跳过本次循环剩余部分**，直接进入下一次 |

```java
// break：找到就停
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;
    System.out.print(i + " ");
}
// 输出：1 2 3 4

// continue：跳过偶数
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;
    System.out.print(i + " ");
}
// 输出：1 3 5 7 9
```

**在嵌套循环中，`break` 和 `continue` 只作用于最内层**：

```java
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break;      // 只跳出内层，外层继续
        System.out.println(i + "," + j);
    }
}
// 输出：0,0  1,0  2,0
```

**要跳出外层循环，用「标签（label）」**：

```java
outer:                              // 定义标签
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break outer;    // 跳出标签指定的循环
        System.out.println(i + "," + j);
    }
}
// 输出：0,0
```

标签语法虽然存在，但**实际开发中很少用**（可读性差）。更推荐的做法是把嵌套循环抽成一个方法，用 `return` 直接退出。

**⚠️ `continue` 在 while 循环中的陷阱**：

```java
int i = 0;
while (i < 5) {
    if (i == 2) continue;       // ❗ 死循环！i 永远停在 2
    System.out.println(i);
    i++;
}
```

`continue` 跳过了 `i++`，导致条件永不改变。**for 循环没有这个问题**，因为变化量在循环体外，`continue` 也会执行它。

### 三种循环的选择

| 场景 | 推荐 |
|---|---|
| 知道确切次数 | **for** |
| 遍历数组 / 集合（不需索引） | **增强 for** |
| 遍历时需要索引或增删元素 | **普通 for / 迭代器** |
| 不知次数，只知结束条件 | **while** |
| 不知次数，且至少执行一次 | **do-while** |

**循环变量的作用域建议**：`for (int i = 0; ...)` 把 `i` 限定在循环内部，出了循环就销毁，避免污染外部作用域。这比 while 写法更安全，也是优先用 for 的一个理由。
