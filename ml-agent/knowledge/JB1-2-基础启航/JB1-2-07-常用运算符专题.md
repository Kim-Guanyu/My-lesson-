## 7.1 数学相关运算符

**本课时对应知识点**：`+`、`-`、`*`、`/`、`%` 等数学运算符。

| 运算符 | 名称 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加 | `5 + 2` | 7 |
| `-` | 减 | `5 - 2` | 3 |
| `*` | 乘 | `5 * 2` | 10 |
| `/` | 除 | `5 / 2` | **2**（整数除法） |
| `%` | 取余（取模） | `5 % 2` | 1 |

**四个必须掌握的细节**：

**① 整数除法会截断小数**：

```java
System.out.println(5 / 2);          // 2    ← 不是 2.5
System.out.println(5.0 / 2);        // 2.5  ← 有一方是浮点就按浮点算
System.out.println(5 / 2.0);        // 2.5
System.out.println((double) 5 / 2); // 2.5  ← 强转一方
System.out.println((double)(5 / 2));// 2.0  ❗ 先算完整数除法再转，为时已晚
```

**② 除零行为不同**：

```java
System.out.println(5 / 0);          // ❌ ArithmeticException: / by zero
System.out.println(5 % 0);          // ❌ ArithmeticException
System.out.println(5.0 / 0);        // Infinity（浮点数不抛异常）
System.out.println(0.0 / 0);        // NaN
```

**③ 取余的符号跟随被除数**：

```java
System.out.println( 5 %  3);        //  2
System.out.println(-5 %  3);        // -2   ← 符号跟随被除数（-5）
System.out.println( 5 % -3);        //  2   ← 符号跟随被除数（5）
System.out.println(-5 % -3);        // -2
```

**④ `+` 遇到字符串变成拼接**（见第 2 单元 2.3 课时）：

```java
System.out.println(1 + 2 + "3");     // "33"
System.out.println("1" + 2 + 3);     // "123"
```

**取余的常见用途**：

```java
// 判断奇偶
if (n % 2 == 0) { /* 偶数 */ }

// 取末位数字
int last = 123 % 10;              // 3

// 循环取值（环形索引）
int index = (i + 1) % arr.length;

// 哈希分桶（分库分表、负载均衡）
int bucket = hash % bucketCount;

// 时间换算
int minutes = totalSeconds / 60;
int seconds = totalSeconds % 60;
```

**Math 类的常用数学方法**（见 JB1-4 数学运算工具）：

```java
Math.abs(-5);            // 5      绝对值
Math.max(3, 7);          // 7      最大值
Math.min(3, 7);          // 3      最小值
Math.pow(2, 10);         // 1024.0 幂运算
Math.sqrt(16);           // 4.0    平方根
Math.round(3.5);         // 4      四舍五入
Math.ceil(3.1);          // 4.0    向上取整
Math.floor(3.9);         // 3.0    向下取整
Math.random();           // [0,1) 随机数
```

**运算符优先级**：`*` `/` `%` 高于 `+` `-`；同级从左向右。**不确定时就加括号** —— 括号不影响性能，却能大幅提升可读性。

## 7.2 赋值相关运算符

**本课时对应知识点**：`=`、`+=`、`-=`、`*=`、`/=`、`%=` 等赋值运算符。

| 运算符 | 等价形式 | 示例 |
|---|---|---|
| `=` | —— | `a = 10` |
| `+=` | `a = a + b` | `a += 5` |
| `-=` | `a = a - b` | `a -= 5` |
| `*=` | `a = a * b` | `a *= 5` |
| `/=` | `a = a / b` | `a /= 5` |
| `%=` | `a = a % b` | `a %= 5` |
| `&=` `\|=` `^=` `<<=` `>>=` `>>>=` | 位运算复合赋值 | |

```java
int a = 10;
a += 5;     // 15
a -= 3;     // 12
a *= 2;     // 24
a /= 4;     // 6
a %= 4;     // 2
```

**复合赋值运算符自带隐式强转（本课时最重要的考点）**：

```java
byte b = 10;
b = b + 5;      // ❌ 编译错误：b+5 结果是 int，不能自动赋给 byte
b += 5;         // ✅ 合法！编译器自动补成 b = (byte)(b + 5)
```

Java 语言规范明确定义：`E1 op= E2` 等价于 `E1 = (T)(E1 op E2)`，其中 T 是 E1 的类型。**这个隐式强转是语言层面强制的**，这也意味着它可能悄悄丢数据：

```java
byte b = 100;
b += 100;               // 200 超出 byte 范围，被截断
System.out.println(b);  // -56  ❗ 没有任何警告
```

**`+=` 对字符串也有效**：

```java
String s = "a";
s += "b";               // "ab"，等价于 s = s + "b"
s += 1;                 // "ab1"，数字自动转字符串
```

但**循环中禁止用 `+=` 拼接字符串**（每次都新建 StringBuilder，性能极差），要用 `StringBuilder.append()`。

**赋值表达式本身有值**：

```java
int a, b;
a = b = 10;             // 从右向左：b=10 的结果是 10，再赋给 a
System.out.println(a);  // 10

int c;
System.out.println(c = 5);   // 5  ← 赋值表达式的值就是赋的那个值
```

**`=` 与 `==` 的混淆**。在 C 语言中 `if (a = 1)` 是合法的（赋值后判断非零），是经典 bug 来源。**Java 中这会直接编译报错**（因为 `if` 要求 boolean），除非变量本身是 boolean：

```java
boolean flag = false;
if (flag = true) { ... }    // ⚠️ 编译通过但逻辑错误！这是赋值不是比较
if (flag == true) { ... }   // 正确（但更推荐直接写 if (flag)）
```

## 7.3 自我相关运算符

**本课时对应知识点**：`++`、`--` 自运算符。

**基本用法**：

```java
int a = 10;
a++;        // 等价于 a = a + 1  →  11
a--;        // 等价于 a = a - 1  →  10
```

**前缀与后缀的区别（面试高频）**：

| 形式 | 名称 | 表达式的值 | 变量最终值 |
|---|---|---|---|
| `a++` | 后缀自增 | **先取原值**，再自增 | 加 1 |
| `++a` | 前缀自增 | **先自增**，再取新值 | 加 1 |

**关键**：无论前缀后缀，**变量本身最终都会加 1**；区别只在于**表达式返回哪个值**。

```java
int a = 10;
int b = a++;       // 先把 10 给 b，a 再变成 11
System.out.println(a + " " + b);   // 11 10

int c = 10;
int d = ++c;       // c 先变成 11，再把 11 给 d
System.out.println(c + " " + d);   // 11 11
```

**记忆口诀**：`++` 在前先加后用，`++` 在后先用后加。

**经典面试题**：

```java
int i = 1;
i = i++;
System.out.println(i);      // 1  ❗ 不是 2！
```

**执行过程分解**：
1. 计算右侧 `i++`：先保存原值 1 到临时位置，然后 `i` 变成 2
2. 执行赋值：把临时位置的 **1** 赋回给 `i`
3. 结果：`i` 又变回了 1

```java
int i = 1;
i = ++i;
System.out.println(i);      // 2  ← 前缀就正常了
```

**更复杂的例子**：

```java
int a = 1;
int b = a++ + ++a;     // a++ 用 1（a变2），++a 先变3再用3  →  1 + 3 = 4
System.out.println(a + " " + b);   // 3 4

int x = 5;
int y = x++ + x++ + x++;   // 5 + 6 + 7 = 18，x 最终为 8
System.out.println(x + " " + y);   // 8 18
```

**自增自减也自带隐式强转**：

```java
byte b = 127;
b++;                    // ✅ 不报错，等价于 b = (byte)(b + 1)
System.out.println(b);  // -128（溢出）
```

**在循环中的用法**：

```java
for (int i = 0; i < 10; i++) { ... }    // 最常见
for (int i = 0; i < 10; ++i) { ... }    // 效果完全相同
```

在 `for` 的第三个表达式中，`i++` 和 `++i` **没有任何区别**，因为返回值被丢弃了。C++ 中 `++i` 对迭代器有性能优势，但 **Java 中两者编译后的字节码基本一致**，不必纠结。

**实践建议**：**不要在一个表达式里多次使用同一变量的自增自减**。`i = i++ + ++i` 这类代码虽然有确定答案，但可读性极差，任何 Code Review 都会打回。自增自减应当独立成句，或只用在循环控制中。

## 7.4 关系相关运算符

**本课时对应知识点**：`>`、`<`、`>=`、`<=`、`==`、`!=` 关系运算符。

**六个关系运算符，结果一律是 `boolean`**：

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `>` | 大于 | `5 > 3` | true |
| `<` | 小于 | `5 < 3` | false |
| `>=` | 大于等于 | `5 >= 5` | true |
| `<=` | 小于等于 | `5 <= 3` | false |
| `==` | 等于 | `5 == 5` | true |
| `!=` | 不等于 | `5 != 3` | true |

**注意事项**：

**① 结果只能是 boolean，不能当数字用**：

```java
int a = (5 > 3);      // ❌ 编译错误：boolean 不能转 int
boolean b = (5 > 3);  // ✅
```

**② `>`、`<`、`>=`、`<=` 只能用于数值类型**（含 char），不能用于 boolean 和引用类型：

```java
System.out.println('a' > 'A');       // true  比较码值 97 > 65
System.out.println("abc" > "abd");   // ❌ 编译错误：String 不能用 >
"abc".compareTo("abd");              // ✅ 返回负数，用 compareTo 比较字符串
```

**③ `==` 和 `!=` 可以用于任何类型，但对引用类型比的是地址**（见 6.5 课时）：

```java
String s1 = new String("abc");
String s2 = new String("abc");
System.out.println(s1 == s2);        // false  地址不同
System.out.println(s1.equals(s2));   // true   内容相同
```

**④ 浮点数不能用 `==` 比较**（见 5.2 课时）：

```java
System.out.println(0.1 + 0.2 == 0.3);              // false ❗
System.out.println(Math.abs(0.1+0.2-0.3) < 1e-9);  // true  ✅
```

**⑤ 不能连写**（这是数学写法，Java 不支持）：

```java
if (1 < x < 10) { ... }              // ❌ 编译错误
if (x > 1 && x < 10) { ... }         // ✅ 必须用逻辑运算符连接
```

原因：`1 < x` 的结果是 boolean，boolean 不能再与 10 比较大小。

**⑥ `=` 与 `==` 不要写错**：

```java
if (a = 5) { ... }        // ❌ 编译错误（除非 a 是 boolean）
if (a == 5) { ... }       // ✅
```

**字符串比较的正确方式汇总**：

```java
s1.equals(s2);                 // 内容相等
s1.equalsIgnoreCase(s2);       // 忽略大小写
s1.compareTo(s2);              // <0 表示 s1 小，=0 相等，>0 表示 s1 大（字典序）
Objects.equals(s1, s2);        // 空安全（两个都是 null 返回 true）
```

## 7.5 逻辑相关运算符

**本课时对应知识点**：`&&`、`||`、`!` 等逻辑运算符。

**六个逻辑运算符**：

| 运算符 | 名称 | 说明 |
|---|---|---|
| `&&` | 短路与 | 两边都为 true 才为 true；**左边为 false 时右边不执行** |
| `\|\|` | 短路或 | 有一边为 true 就为 true；**左边为 true 时右边不执行** |
| `!` | 非 | 取反 |
| `&` | 逻辑与 | 与 `&&` 结果相同，但**两边都会执行** |
| `\|` | 逻辑或 | 与 `\|\|` 结果相同，但**两边都会执行** |
| `^` | 异或 | 两边不同为 true，相同为 false |

**真值表**：

| a | b | a && b | a \|\| b | !a | a ^ b |
|---|---|---|---|---|---|
| true | true | true | true | false | false |
| true | false | false | true | false | true |
| false | true | false | true | true | true |
| false | false | false | false | true | false |

**短路特性（本课时最重要的知识点）**：

```java
int a = 0;
// && 短路：左边 false，右边的 a++ 不执行
if (false && (a++ > 0)) { }
System.out.println(a);      // 0  ← a 没有自增

int b = 0;
// & 不短路：两边都执行
if (false & (b++ > 0)) { }
System.out.println(b);      // 1  ← b 自增了
```

**短路的实际价值：防止空指针**（这是最重要的应用）：

```java
String s = null;

// ✅ 正确：s == null 为 true，短路，不执行 s.length()
if (s == null || s.length() == 0) { ... }

// ❌ 错误：| 不短路，s.length() 一定会执行 → NullPointerException
if (s == null | s.length() == 0) { ... }

// ✅ 另一个方向的例子
if (user != null && user.getName().equals("张三")) { ... }
```

**这个「判空 + 短路」的写法在实际项目中随处可见**，是必须形成的肌肉记忆。

**短路还能提升性能**。把开销小、最可能决定结果的条件放在前面：

```java
// ✅ 先做廉价的判断，能短路就不查数据库
if (id != null && id > 0 && userService.exists(id)) { ... }
```

**`^` 异或的特性**（在位运算中更常用）：

```java
System.out.println(true ^ true);    // false  相同为 false
System.out.println(true ^ false);   // true   不同为 true
```

异或有一个著名性质：**同一个数异或两次等于原数**（`a ^ b ^ b == a`），可用于简单加密和无临时变量交换。

**运算符优先级**：`!` > `&&` > `||`。混合使用时建议加括号：

```java
if (a || b && c) { ... }        // 实际是 a || (b && c)
if ((a || b) && c) { ... }      // 加括号明确意图
```

**德摩根定律（简化复杂条件的利器）**：

```java
!(a && b)  等价于  !a || !b
!(a || b)  等价于  !a && !b
```

```java
// 原式
if (!(age >= 18 && hasLicense)) { ... }
// 化简后，更易读
if (age < 18 || !hasLicense) { ... }
```

**实践建议**：条件超过三个时，抽成一个有意义的布尔变量或方法：

```java
// ❌ 难读
if (user != null && user.getAge() >= 18 && user.isActive() && !user.isBanned()) { ... }

// ✅ 意图清晰
boolean canPurchase = user != null && user.getAge() >= 18
                   && user.isActive() && !user.isBanned();
if (canPurchase) { ... }
```

## 7.6 比特相关运算符

**本课时对应知识点**：`&`、`|`、`~`、`^`、`<<`、`>>`、`>>>` 等位运算符。

**位运算直接操作二进制位**，是最贴近硬件的运算，效率极高。

| 运算符 | 名称 | 规则 |
|---|---|---|
| `&` | 按位与 | 两位都是 1 才是 1 |
| `\|` | 按位或 | 有一位是 1 就是 1 |
| `^` | 按位异或 | 两位**不同**为 1 |
| `~` | 按位取反 | 0 变 1，1 变 0（含符号位） |
| `<<` | 左移 | 整体左移，右边补 0 |
| `>>` | 右移（算术右移） | 整体右移，**左边补符号位** |
| `>>>` | 无符号右移 | 整体右移，**左边一律补 0** |

**运算示例**（以 8 位演示，实际 int 是 32 位）：

```java
int a = 12;    // 0000 1100
int b = 10;    // 0000 1010

System.out.println(a & b);    // 8    0000 1000
System.out.println(a | b);    // 14   0000 1110
System.out.println(a ^ b);    // 6    0000 0110
System.out.println(~a);       // -13  取反后是补码，见下面解释
```

**`~` 取反的规律**：`~n == -(n + 1)`

```java
System.out.println(~12);      // -13
System.out.println(~0);       // -1
System.out.println(~-1);      // 0
```

**推导**：`-n` 的补码 = `~n + 1`（见 3.3 课时），移项得 `~n = -n - 1 = -(n+1)`。

**移位运算**：

```java
System.out.println(8 << 1);     // 16    左移1位 = ×2
System.out.println(8 << 2);     // 32    左移2位 = ×4
System.out.println(8 >> 1);     // 4     右移1位 = ÷2
System.out.println(-8 >> 1);    // -4    算术右移，补符号位 1
System.out.println(-8 >>> 1);   // 2147483644  无符号右移，补 0
```

**移位的本质**：`a << n` 等价于 `a × 2ⁿ`；`a >> n` 等价于 `a ÷ 2ⁿ`（向下取整）。**移位比乘除快得多**，因为 CPU 只需移动电路中的位。

**`>>` 与 `>>>` 的关键区别**：

```java
int x = -8;                                 // 补码 111...11111000
System.out.println(Integer.toBinaryString(x >> 1));
// 11111111111111111111111111111100   ← 高位补 1，仍是负数 -4

System.out.println(Integer.toBinaryString(x >>> 1));
// 01111111111111111111111111111100   ← 高位补 0，变成大正数 2147483644
```

**对正数而言 `>>` 和 `>>>` 结果相同**；只有负数才有区别。Java 没有 `<<<`，因为左移低位一律补 0，不存在符号问题。

**移位位数的隐含取模**：`a << n` 中 n 会先对 32（int）或 64（long）取模：

```java
System.out.println(1 << 32);    // 1  ❗ 因为 32 % 32 = 0，等于没移
System.out.println(1 << 33);    // 2  因为 33 % 32 = 1
```

**位运算的实际应用**：

**① 判断奇偶（比 `% 2` 快）**：

```java
if ((n & 1) == 1) { /* 奇数 */ }
```

**② 快速乘除 2 的幂**：

```java
int half = n >> 1;         // n / 2
int twice = n << 1;        // n * 2
```

HashMap 源码中大量使用这类技巧，如 `(n - 1) & hash` 替代 `hash % n`（当 n 是 2 的幂时两者等价，但位运算快得多）。

**③ 权限位掩码（Linux 文件权限就是这个原理）**：

```java
static final int READ    = 1;      // 0001
static final int WRITE   = 1 << 1; // 0010
static final int EXECUTE = 1 << 2; // 0100

int perm = READ | WRITE;                        // 0011 授予读写权限
boolean canRead = (perm & READ) != 0;           // true  检查权限
perm |= EXECUTE;                                // 追加权限
perm &= ~WRITE;                                 // 移除权限
```

**④ 交换两个数（不用临时变量）**：

```java
a = a ^ b;
b = a ^ b;      // b = (a^b)^b = a
a = a ^ b;      // a = (a^b)^a = b
```

（面试题常考，但实际开发中用临时变量更清晰，不要炫技。）

**⑤ 找出数组中唯一不重复的数字**：

```java
// 其余数字都出现两次，异或后成对抵消，剩下的就是答案
int result = 0;
for (int n : nums) result ^= n;
```

**位运算符与逻辑运算符的重合**。`&`、`|`、`^` 作用于 boolean 时是逻辑运算（不短路），作用于整数时是位运算。**日常写条件判断一律用 `&&` 和 `||`**，因为短路能防空指针、还能提升性能。

## 7.7 三目逻辑运算符

**本课时对应知识点**：`X ? Y : Z` 基础格式、结构特点、嵌套方式。

**基础格式**：

```java
条件表达式 ? 值1 : 值2
```

条件为 `true` 返回值1，为 `false` 返回值2。它是 Java 中**唯一的三元运算符**（需要三个操作数）。

```java
int a = 10, b = 20;
int max = a > b ? a : b;                 // 20

String result = score >= 60 ? "及格" : "不及格";
```

**与 if-else 的对比**：

```java
// if-else 写法
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}

// 三目运算符写法（一行搞定）
int max = a > b ? a : b;
```

**核心区别：三目运算符是「表达式」，有返回值；if-else 是「语句」，没有返回值**。所以三目运算符能直接嵌入到其他表达式中：

```java
System.out.println(a > b ? "大" : "小");           // ✅ 直接作参数
String s = "结果：" + (a > b ? "大" : "小");        // ✅ 参与拼接
list.add(flag ? "yes" : "no");                    // ✅
int[] arr = new int[flag ? 10 : 20];              // ✅
```

if-else 在这些位置都用不了。

**结构特点**：

1. **必须有 `:` 和两个分支**，不能只写一个（不像 if 可以没有 else）
2. **两个分支的类型必须兼容**，会做类型提升
3. 返回值必须被使用（不能单独成句）：

```java
a > b ? a : b;          // ❌ 编译错误：不是语句
int max = a > b ? a : b; // ✅
```

**类型提升的陷阱（重要考点）**：

```java
Object o = true ? new Integer(1) : new Double(2.0);
System.out.println(o);      // 1.0  ❗ 不是 1！
```

**原因**：三目运算符会把两个分支**提升到共同的类型**。Integer 和 Double 的共同数值类型是 double，所以 Integer 1 被转成了 1.0。

**更危险的空指针版本**：

```java
Integer i = null;
int result = true ? i : 0;    // ❌ NullPointerException
```

因为另一个分支是 `int`，编译器会把整个表达式提升为 `int`，导致 `i` 被自动拆箱，而 `i` 是 null。这是实际项目中非常隐蔽的一个 bug。

**嵌套方式**：

```java
// 三个数求最大值
int max = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);

// 成绩分级
String level = score >= 90 ? "优秀"
             : score >= 80 ? "良好"
             : score >= 60 ? "及格"
             : "不及格";
```

第二种写法利用了三目运算符的**右结合性**（从右向左结合），实际等价于：

```java
score >= 90 ? "优秀" : (score >= 80 ? "良好" : (score >= 60 ? "及格" : "不及格"))
```

这种「阶梯式」的排版是三目嵌套的推荐写法，可读性接近 `if-else if` 链。

**嵌套的使用原则**：

- **一层嵌套可以接受**，格式化好就行
- **超过两层就改用 if-else 或 switch**，可读性会急剧下降
- 绝对不要写成一行：`a>b?a>c?a:c:b>c?b:c` 这种代码是团队灾难

**实用场景**：

```java
// ① 空值兜底
String name = user.getName() != null ? user.getName() : "匿名";
// JDK 9+ 更推荐用 Optional 或 Objects.requireNonNullElse
String name2 = Objects.requireNonNullElse(user.getName(), "匿名");

// ② 单复数
System.out.println(count + " item" + (count > 1 ? "s" : ""));

// ③ 状态转文字
String status = order.getStatus() == 1 ? "已付款" : "未付款";

// ④ 安全除法
int avg = count == 0 ? 0 : total / count;

// ⑤ 取绝对值
int abs = n >= 0 ? n : -n;
```

**实践建议**：三目运算符适合**简单的二选一取值**。如果分支里有复杂逻辑、有副作用（如调用会修改状态的方法）、或者需要多条语句，一律用 if-else。**代码的第一读者是人，简洁不等于晦涩**。
