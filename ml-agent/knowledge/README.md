# 知识库源文档目录

小精灵回答学习类问题的资料就放在这里。

## 怎么用

1. 往本目录放入文档，支持 `.md` / `.txt` / `.pdf` / `.docx`
   （pdf 和 docx 需要先装可选依赖：`pip install pypdf docx2txt`）
2. 建索引：

   ```bash
   python scripts/ingest.py            # 增量追加
   python scripts/ingest.py --rebuild  # 清空重建（改过已有文档后用这个）
   ```

3. 索引产物落在 `ml-agent/data/vectorstore`，已在 `.gitignore` 中忽略，
   随时可以重建，不需要提交。

## 放什么内容效果最好

小精灵的核心场景是「学员看视频卡住了，来问一句」。所以最有价值的是**能对应到
具体课时的讲解内容**：

- 课程讲稿、课件文字、章节要点整理
- 概念解释、术语表
- 课后答疑整理、常见错误分析

建议在文档里保留章节标题层级（Markdown 的 `#` / `##`），切片时会按段落边界切分，
标题能帮助保留上下文。

如果文档能标注对应的课时，检索结果的指向性会更强，例如：

```markdown
## 第3章 第2节 索引失效的常见场景

（正文……）
```

## 文件命名

文件名（不含扩展名）会作为检索结果的「来源」回显给模型，模型可能会在回答里
提到出处。所以建议用有意义的名字，例如 `MySQL索引原理讲稿.md`，
而不是 `doc1.md`。
