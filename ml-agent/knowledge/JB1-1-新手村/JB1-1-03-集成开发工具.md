## 3.1 IDEA开发工具安装

**本课时对应知识点**：IDE 概念、IDE 产品、IDEA 卸载与安装、正版授权途径。

**什么是 IDE**。IDE = Integrated Development Environment 集成开发环境。它把编辑器、编译器、调试器、版本控制、构建工具、数据库客户端等整合到一个界面里。用命令行 `javac` + `java` 也能写 Java（见第 2 单元），但项目一旦有几十个类、多层包结构和外部依赖，手动编译就完全不现实了。IDE 的核心价值是**代码提示、即时错误检查、一键运行调试、自动重构**。

**主流 Java IDE 产品**：

| 产品 | 特点 |
|---|---|
| **IntelliJ IDEA** | JetBrains 出品，Java 领域事实标准，智能提示最强，框架支持最好 |
| Eclipse | 开源免费，插件生态庞大，老项目和部分企业仍在用 |
| VS Code + Java 扩展包 | 轻量、启动快，适合小项目和多语言混合开发 |
| NetBeans | Apache 维护，开箱即用，国内使用较少 |

**IDEA 的两个版本**：

- **Community Edition（社区版）** —— **完全免费、开源**。支持 Java、Maven、Gradle、Git、JUnit、调试器，学 JB1 全部基础课程**完全够用**。
- **Ultimate Edition（旗舰版）** —— 付费。额外支持 Spring / Spring Boot 深度集成、数据库工具、HTTP Client、前端框架、微服务工具等。学到 JB3 框架阶段后会明显感到差异。

**合法获取旗舰版的三条途径**：

1. **学生 / 教师免费授权** —— 用学校邮箱（edu 域名）或学信网学籍证明在 JetBrains 官网申请，可免费使用全部产品，每年续期。这是学生最应该走的路径。
2. **30 天免费试用** —— 官网注册账号即可，到期后可切回社区版。
3. **开源项目授权** —— 维护活跃开源项目可申请免费许可。

> 关于「破解」：这部分内容我不提供。绕过授权属于侵权，而且破解补丁常被植入后门 —— 你的代码、Git 凭据、数据库密码都在 IDE 里。上面三条途径足以覆盖学习需求，学生授权尤其推荐。

**安装要点**：官网 <https://www.jetbrains.com/idea/download/> 下载；安装路径避免中文和空格；勾选「Add bin folder to the PATH」和「.java 文件关联」；内存建议 8G 以上（IDEA 比较吃内存）。

**彻底卸载**（重装前必须做干净，否则旧配置会被继承）：控制面板卸载程序时勾选删除配置和缓存，然后手动删除残留目录：

- Windows：`C:\Users\用户名\AppData\Roaming\JetBrains`、`C:\Users\用户名\AppData\Local\JetBrains`
- 项目里的 `.idea` 目录也是 IDEA 生成的配置（可以安全删除，下次打开会重建）

## 3.2 IDEA创建基础项目

**本课时对应知识点**：用 IDEA 创建项目、开发 HelloWorld、Java 项目 / 包 / 类命名规范。

**创建项目**：`File → New → Project` → 左侧选 `New Project` → 填 Name（项目名）、Location（路径）→ 选 JDK（若列表为空点 `Add JDK` 指向 JDK 根目录）→ Build system 选 `IntelliJ`（纯 Java 练习）或 `Maven`（需要依赖管理时）→ Create。

**项目结构**：

```
my-project/
├── .idea/          IDEA 配置目录（不需要手动管理，可加入 .gitignore）
├── src/            源码根目录，包和类都放这里
└── my-project.iml  模块描述文件
```

**写第一个类**：右键 `src` → `New → Package` 建包（如 `com.mdkj.demo`）→ 右键包 → `New → Java Class` → 输入 `HelloWorld`。IDEA 会自动补好 `package` 声明和类骨架。

方法体里输入 `sout` 再按 Tab —— 自动展开成 `System.out.println();`，这是最常用的 Live Template。然后点行号旁的绿色三角运行，或 `Ctrl + Shift + F10`。

**三层命名规范**（阿里巴巴 Java 开发手册标准）：

**项目命名** —— 全小写，多个单词用中划线连接：`my-lesson`、`user-service`。不要用中文、空格、下划线开头。

**包命名** —— **全小写**，用点分隔，采用**倒置域名**开头，保证全球唯一：

```
com.mdkj.controller     // 控制层
com.mdkj.service        // 业务层
com.mdkj.service.impl   // 业务实现
com.mdkj.entity         // 实体类
com.mdkj.util           // 工具类
com.mdkj.config         // 配置类
```

包名对应磁盘上的目录层级：`com.mdkj.demo` 就是 `com/mdkj/demo/` 三级目录。包的作用是**避免类名冲突**并组织代码结构。

**类命名** —— **大驼峰（UpperCamelCase）**，用名词：`HelloWorld`、`UserService`、`OrderController`。常见后缀约定：

| 后缀 | 含义 |
|---|---|
| `XxxController` | 控制层，接收请求 |
| `XxxService` / `XxxServiceImpl` | 业务接口 / 实现 |
| `XxxMapper` / `XxxDao` | 数据访问层 |
| `XxxUtil` / `XxxUtils` | 工具类 |
| `XxxConfig` | 配置类 |
| `XxxException` | 异常类 |
| `XxxTest` | 测试类 |
| `XxxDTO` / `XxxVO` | 数据传输对象 / 视图对象 |

**方法与变量命名** —— **小驼峰（lowerCamelCase）**，方法用动词开头：`getUserById`、`saveOrder`、`isDeleted`。布尔类型的方法习惯用 `is` / `has` / `can` 开头。

**常量命名** —— 全大写，下划线分隔：`MAX_RETRY_COUNT`、`DEFAULT_PAGE_SIZE`。

## 3.3 IDEA基础环境配置

**本课时对应知识点**：禁用自动更新、调整字体大小、设置字符编码、设置代码模板、隐藏配置文件、启用自动导包、展示方法分隔线、修改默认终端。

配置入口统一是 `File → Settings`（macOS 是 `IntelliJ IDEA → Preferences`），快捷键 `Ctrl + Alt + S`。

**① 禁用自动更新** —— `Appearance & Behavior → System Settings → Updates`，取消勾选 `Check IDE updates`。避免版本跳变导致插件失效或授权状态变化。

**② 调整字体大小** —— 编辑器字体：`Editor → Font`，Size 建议 16–18，Line height 1.2–1.4。界面字体：`Appearance & Behavior → Appearance → Use custom font`。快捷方式：`Editor → General` 勾选 `Change font size with Ctrl+Mouse Wheel`，之后按住 Ctrl 滚滚轮即可缩放。

**③ 设置字符编码（重要）** —— `Editor → File Encodings`，把 `Global Encoding`、`Project Encoding`、`Default encoding for properties files` **全部设为 UTF-8**，并勾选 `Transparent native-to-ascii conversion`。

> 这一步不做，中文注释和中文字符串在换机器或换系统后会变成乱码 —— 因为 Windows 默认用 GBK，而 Git 仓库和 Linux 服务器用 UTF-8。这是中文开发者最高频的踩坑点之一。

**④ 设置代码模板（文件头注释）** —— `Editor → File and Code Templates → Files → Class`，在模板顶部加入：

```java
/**
 * ${DESCRIPTION}
 *
 * @author 你的名字
 * @date ${DATE} ${TIME}
 */
```

以后新建类会自动带上作者和时间。也可以在 `Editor → Live Templates` 里自定义代码片段（类似 `sout`、`psvm` 这种缩写展开）。

**⑤ 隐藏配置文件** —— `Editor → File Types → Ignored Files and Folders`，加入 `*.iml`、`.idea`、`target` 等。让项目树只显示你关心的源码。

**⑥ 启用自动导包** —— `Editor → General → Auto Import`，勾选：

- `Add unambiguous imports on the fly` —— 输入类名时自动补 `import`
- `Optimize imports on the fly` —— 自动删除无用的 import

省掉大量手动 `Alt + Enter` 的操作。

**⑦ 展示方法分隔线** —— `Editor → General → Appearance`，勾选 `Show method separators`。方法之间会画一条淡淡的横线，长类的可读性明显改善。

**⑧ 修改默认终端** —— `Tools → Terminal → Shell path`。Windows 默认是 `cmd.exe`，可改为 Git Bash（`D:\develop\Git\bin\bash.exe`）或 PowerShell。改成 Git Bash 的好处是能直接用 `ls`、`grep`、`curl` 这些 Linux 命令，与后面 JB2 的 Linux 课程衔接顺畅。

**其他值得一起打开的设置**：

- `Editor → General → Code Completion` 取消勾选 `Match case`，让代码提示不区分大小写
- `Editor → General → Smart Keys` 勾选 `Use "CamelHumps" words`，双击可按驼峰选中单词
- `Build, Execution, Deployment → Compiler` 勾选 `Build project automatically`
- `Editor → Code Style → Java` 设置缩进为 4 空格

**必备快捷键速查**：

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + S` | 打开设置 |
| `Shift + F10` / `Ctrl + Shift + F10` | 运行上次 / 运行当前 |
| `Shift + F9` | 调试 |
| `Ctrl + D` | 复制当前行 |
| `Ctrl + Y` | 删除当前行 |
| `Ctrl + Alt + L` | 格式化代码 |
| `Ctrl + Alt + O` | 优化导包 |
| `Alt + Enter` | 万能修复提示（最常用） |
| `Ctrl + B` / `Ctrl + Alt + B` | 跳转到声明 / 跳转到实现 |
| `Ctrl + Alt + ←/→` | 后退 / 前进（跳转历史） |
| `Ctrl + F12` | 查看当前类结构 |
| `Shift + Shift` | 全局搜索任何东西 |
| `Ctrl + Shift + F` | 全局按内容搜索 |
| `Ctrl + R` / `Ctrl + Shift + R` | 当前文件替换 / 全局替换 |
| `Shift + F6` | 重命名（自动改所有引用处） |
| `Ctrl + Alt + M` | 抽取方法 |
| `Ctrl + P` | 查看方法参数 |
| `Alt + Insert` | 生成构造器 / getter / setter / toString |

## 3.4 IDEA常用插件分享

**本课时对应知识点**：Translation、Alibaba Java Coding Guidelines、Gitee、Maven Helper、jclasslib Bytecode Viewer、Vue.js、Redis Helper、Archive Browser、Lombok。

安装入口：`File → Settings → Plugins → Marketplace`，搜名字点 Install，装完重启 IDEA。

**Translation** —— 划词翻译。选中英文按 `Ctrl + Shift + Y` 直接出中文。对读官方文档和英文报错帮助极大。支持接入有道、百度、Google 等翻译源。

**Alibaba Java Coding Guidelines** —— 阿里巴巴 Java 开发规约插件。实时扫描代码并标出违规项（命名不规范、循环里拼接字符串、忽略异常、缺少注释等），每条都给出规约依据和修改建议。**对初学者极有价值**：它把「什么是好代码」这件事具体化成了可执行的检查项。右键 `编码规约扫描` 可扫描整个项目。

**Gitee** —— 码云官方插件。让 IDEA 能直接分享项目到 Gitee、克隆 Gitee 仓库、管理 Pull Request。国内访问 Gitee 比 GitHub 稳定，第 6 单元的项目协同就用它。

**Maven Helper** —— 解决 Maven **依赖冲突**的利器。打开 `pom.xml` 后底部多出 `Dependency Analyzer` 标签，能以树形展示所有依赖，一键找出冲突（同一个包被引入多个版本）并生成 `<exclusion>` 排除配置。学到 JB3 框架阶段几乎天天要用。

**jclasslib Bytecode Viewer** —— 字节码查看器。`View → Show Bytecode With Jclasslib` 可以看到当前类编译后的字节码结构（常量池、方法表、指令）。用来验证「语法糖」到底变成了什么 —— 例如自动装箱其实是 `Integer.valueOf()`（见 JB1-2 装箱和拆箱过程）、字符串 `+` 拼接其实是 `StringBuilder`（见 JB1-4 字符拼接工具）、增强 for 循环其实是迭代器。**理解原理的神器**。

**Vue.js** —— Vue 语法高亮与提示，学到 JB3-9 Vue 课程时需要。（IDEA Ultimate 内置，社区版需要装。）

**Redis Helper** —— 在 IDEA 里连接 Redis、浏览键值、执行命令，不用切到命令行。JB3-5 Redis 课程会用到。

**Archive Browser** —— 直接在 IDEA 里查看 jar / zip / tar 包内容，不用解压。排查「依赖里到底有没有这个类」时很方便。

**Lombok** —— 让 IDEA 识别 `@Data`、`@Getter` 等注解生成的方法，消除「找不到 getXxx() 方法」的红色报错。**注意**：IDEA 2020.3 以后已内置 Lombok 支持，通常不需要额外安装；但项目里仍需在 `pom.xml` 引入 lombok 依赖（见 JB1-3 龙目岛工具类）。

**其他值得一装的插件**：

- **Key Promoter X** —— 你用鼠标点菜单时弹出对应快捷键提示，强制养成键盘习惯
- **Rainbow Brackets** —— 括号按层级着色，嵌套深的代码不再数括号
- **GenerateAllSetter** —— 一键生成某个对象所有字段的 `setXxx()` 调用
- **String Manipulation** —— 大小写转换、驼峰下划线互转、字符串排序
- **Restfultool / RestfulFast** —— 按接口路径直接跳转到对应 Controller 方法
- **MybatisX** —— Mapper 接口与 XML 之间双向跳转，JB3-1 MyBatis 课程必备

**插件不宜过多**：每个插件都占内存并拖慢启动。建议只留真正在用的，其余禁用（Plugins 里取消勾选即可，不必卸载）。
